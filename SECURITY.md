# Security Policy

## Supported versions

Security fixes go to the latest release of the current major version, so upgrade to that version to receive one.

## Reporting a vulnerability

Do not open a public issue. Use [GitHub's private vulnerability reporting](https://github.com/alaeddineG/Wkeel/security/advisories/new) instead, which keeps the report visible only to the maintainer until a fix is ready.

Include the affected version or commit, reproduction steps and the impact you expect. Wkeel is maintained on a volunteer basis, so reports are handled on a best-effort schedule.
